# fluit.es

Website for [Fluit Coop. V.](https://fluit.es) — a hydraulic engineering, software & AI cooperative based in Valencia, Spain.

## Stack

- React 19 + React Router
- Vite
- Framer Motion
- Lucide icons

## Development

Requires [pnpm](https://pnpm.io) and [just](https://just.systems). Run `just` to list the recipes.

```bash
just install
just dev
```

## Build

```bash
just build
just preview  # local preview of the build
```

## Deployment

The site is deployed to [fluit.es](https://fluit.es) from the `main` branch.
